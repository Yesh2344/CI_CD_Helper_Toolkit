# CI/CD Helper Toolkit

[![Gem Version](https://badge.fury.io/rb/ci_cd_helper_toolkit.svg)](https://badge.fury.io/rb/ci_cd_helper_toolkit)
[![Build Status](https://github.com/yourusername/ci_cd_helper_toolkit/actions/workflows/ci.yml/badge.svg)](https://github.com/yourusername/ci_cd_helper_toolkit/actions)

A production‑ready Ruby library that simplifies building and managing CI/CD pipelines. 
It provides:

* **Configuration handling** – loads from `.env` and `config.yml`.
* **Structured logging** – JSON‑compatible logs with adjustable levels.
* **Pipeline orchestration** – declarative step definition with robust error handling.
* **Utility helpers** – safe shell command execution, environment variable fetching, etc.
